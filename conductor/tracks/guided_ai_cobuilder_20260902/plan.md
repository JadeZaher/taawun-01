# Guided AI Co-builder Execution Plan

## Phase 1 — Make the safe path obvious

- [ ] Replace the collapsed empty-workspace disclosure with one visible primary
  “Create your workspace” step and plain-language context.
- [ ] Add Guided and Advanced modes; default new/empty workspaces to Guided.
- [ ] Implement the eight-step deterministic journey on the existing catalog and
  draft contracts, with Back, Skip, Undo, Save and exit, and resume.
- [ ] Present one recommended template and initial section set from purpose and
  audience answers; explain recommendations without technical IDs.
- [ ] Fix custom-field rename focus/rerender continuity and add signed round-trip
  regression coverage.
- [ ] Move raw JSON, exact origins, track lookup, receipts, event history, finance,
  Shura, Bazaar, and destructive account controls behind contextual progressive
  disclosure while preserving direct Advanced access.

## Phase 2 — Trustworthy assistant proposals

- [ ] Define a versioned typed proposal schema mapped to catalog/template/
  component document fields; reject unknown capabilities and arbitrary code.
- [ ] Add an assistant panel scoped to the current guided step with Apply, Edit,
  Reject, explanation, limitation, and provider-offline fallback states.
- [ ] Redact credentials, invitation secrets, capabilities, unrelated workspace
  data, and private keys from assistant context and telemetry.
- [ ] Require the existing explicit product confirmation for invitations,
  removals, domains, publication, rollback, revocation, and deletion.
- [ ] Add deterministic provider fixtures plus live opt-in smoke coverage without
  making live model availability a requirement for manual completion.

## Phase 3 — Validate with people

- [ ] Test first preview, edit/rebuild, protected review, and publication-readiness
  comprehension with five representative non-technical organizers.
- [ ] Record time, deliberate controls, wrong turns, recovery, Advanced use, and
  state-language comprehension in the live QA runbook.
- [ ] Promote only evidence-backed wording and remedies; never infer participant
  success from automated browser behavior.
