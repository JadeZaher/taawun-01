# Decisions

## Guidance is the default; advanced capability remains available

New and empty workspaces start in Guided mode. Advanced mode keeps the complete
operator surface and shares the exact same typed draft; it is not a separate
builder or a lossy export.

## Deterministic guidance ships before provider-dependent assistance

The core journey must remain completable when no model provider is configured or
available. AI adds proposals and explanations, not basic product availability.

## The assistant proposes; product authority decides

Assistant output is untrusted declarative input. Catalog validation, workspace
roles, signed previews, domain proof, and explicit confirmations remain the
authority boundaries. The assistant cannot create permissions or public serving
state by narration.
